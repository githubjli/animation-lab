# 粗动态分镜 v0.1

2026-10-14。实际文件：animatic-v0.1.mp4，45秒，960×540，24fps H264/AAC；独立姿态采样12fps。使用Pillow绘制简化角色和位置变化，FFmpeg编码，包含原创合成计时与快门临时音效。不是最终角色设计、完整角色动画或正式配乐。

本版基于 ../BEATS-v0.1.md；未使用参考图或生成模型，未进行付费提交。构建方式：在已具备Pillow、Noto CJK字体和FFmpeg的环境运行 python3 build_v01.py。输入文本版本与代码保留于本目录及上级；实际输出哈希见record-v0.1.json。后续版本使用新文件名，不覆盖本版候选。

已检查：45秒时长、音视频流、完整解码；已查看10镜总览。尚未完成：连续人工音画评审、参考视频连续对照、独立观看者理解测试。

观看顺序：先不读说明看视频，再用contact-sheet-v0.1.jpg讨论具体镜头。当前全景为主，屏幕插入为简化重建；正式版需要补眼神与反应镜头设计。围巾抓取、手部接触、迈步和坐倒仅示意位置与时机，不能据此认定动画流畅、动作可信或视觉验收通过。

首轮评审问题：
- 0—14秒是否能看懂狐狸想要整齐合影，以及熊挡住狐狸造成的尴尬？
- 14—25秒遮脸和帮助是否重复或过长？
- 25—31秒重新计时是否拖沓？当前30秒启动、40秒快门需要在调整节拍时保持一致。
- 31—38秒追逐与坐倒是否看得清，而不是仅由字幕解释？
- 38—45秒是否有足够时间从惊讶到笑，再理解狐狸接受意外合影？

本版仅建立可播放的节奏讨论材料，没有证据支持已达到或超过Michelin专业度。
