# Animation Lab 可执行质量标准 v0.1
更新：2026-10-09。定位：制作与验收规范，不是已达成的质量认证。

## 标准的证据层级
|类别|目前内容|使用方法|
|---|---|---|
|实际文件证据|Michelin 故事板、短提示词、本地15.072秒成片及来源哈希|直接查看和对照|
|已观察的参考优点|角色轮廓反差、暖色统一、环境层次、反应镜头、帽子贯穿|作为分析方向；逐段连续审片后补时间码|
|项目制作规范|下表及上下游规则|作为新片的验收要求，不宣称案例每项都通过|
|待验证假设|分段15秒、参考图数量、提示词长度、30秒故事节奏|通过实验比较，不升级为通用结论|

高质量指叙事、设计、运动、剪辑和声音协同成立。720p或4K、长提示词、复杂毛发、电影风格关键词均不能独立证明质量。

## 分项验收表
|维度|固定物料/规则|通过时应看到什么|返工信号|
|---|---|---|---|
|故事与情绪|因果链、动机、结尾回应|不依赖说明文字也能看懂阻拦、误解、发现、帮助|只有漂亮画面；转折无原因；温暖结尾靠硬加旁白|
|人物设计|比例、轮廓、脸部识别点、配色、服装、表情范围|正侧面和不同景别仍是同一人；人物有视觉区别|换脸、身高忽变、服装漂移|
|环境设计|布局图、左右关系、出入口、干湿区域|长椅、台阶、警示牌位置能在镜头间对应|背景重建、位置跳变、台阶突然出现|
|光影与色彩|主光方向、冷暖关系、曝光和材质参考|主体可读；脸有层次；接触阴影可信；镜头间色调一致|白部过曝、暗部糊黑、逆光吞脸、光源方向无故翻转|
|材质与造型|统一风格主参考|动物、衣服、道具与环境处在同一视觉体系|部分写实部分玩具感；锐化/皮肤塑料感破坏统一|
|镜头语言|景别、主体、轴线、镜头目的|全景交代空间，细节呈现原因，反应呈现情绪|无理由切镜、越轴误导、持续推拉掩盖动作|
|动作表演|起势→接触/执行→结果→反应|重量、接触和停顿清楚；动作服务剧情|滑步、穿模、道具瞬移、无预备突然变姿势|
|道具连续性|持有者、数量、位置、状态表|接触后才沾漆；帕从包取出；警示牌由倒变立|接触前脏手、手帕凭空出现、擦手后又沾漆|
|时间与节奏|逐镜秒数、动态分镜|观众来得及看清关键动作和反应；快慢有变化|多动作挤在短镜头；对白抢画面；停留无信息|
|对白与声音|台词、说话者、临时音轨、后期分轨|台词自然清晰，与动作关系明确；音乐不遮语音|靠字幕猜台词；音量突变；错误说话者；有口型却严重不同步|
|生成输入|引用图编号、图序、提交原文、参数和哈希|身份/空间/构图/运动约束一致且可追溯|图片与文字冲突；上传图序未知却声称可复现|
|交付|原始候选、工程或剪辑记录、最终输出信息|可追溯版本；正常播放；时长与音画经实际检查|只留下一个FINAL文件；失败候选覆盖；假报分辨率|

当前镜头表的35/50/85mm等是透视与景别意图，不是生成视频已具备可验证真实焦距的声明。

## 质量门槛
每项评分：0失败 / 1需修 / 2通过 / N/A有说明。
- 视觉资产门：身份、空间、光影风格统一后才制作正式分镜。
- 分镜门：构图顺序、道具状态、因果和30秒节拍成立后才组生成包。
- 试片门：连续观看并检查关键接触段，记录时间码与截图；不能用抽帧代替运动审片。
- 成片门：所有适用项目达到2；暂时保留的问题必须明确标注为测试版，不能称最终高质量交付。
- 换脸、关键穿模/接触失败、重要道具瞬移、关键因果缺失为阻断项，不以总分平均掩盖。
- 模型执行不了时优先拆动作、改景别或减少道具，再改提示词；每次改变需留版本记录。

## 首集风格基线
成年气质的拟人狐狸与兔子，雨后公园，左后暖日光、冷天光补脸；横屏16:9，24fps，30秒目标。
狐狸蓝灰外套米色裤子；兔子苔绿背心帆布包。主参考、精确色板、角色比例和音色尚未制作确认。
先达到统一、清晰、可信，再决定更高分辨率；超分不能修复造型、接触和叙事错误。

## 如何积累可用经验
每轮保存：输入清单与顺序 → 实际提交内容 → 已知参数 → 原始输出 → 带时间码的观察 → 原因假设 → 下一轮变量。
观察与推断分栏。保留失败和反例。重复出现且有证据的结论才进入知识库规则；注明模型/版本、故事类型与适用边界。
